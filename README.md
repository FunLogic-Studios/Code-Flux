# CodeFlux

> A focused desktop coding environment for C# and GDScript.

CodeFlux is a lightweight desktop code editor designed for developers who want a clean, stylish and focused environment for writing **C#** and **GDScript**.

Built by **FunLogic Studios**.

## Features

- C# development
- GDScript development
- Syntax highlighting
- Pre-written code templates
- Fast template insertion
- Clean and focused interface
- File and project management
- Dark developer-focused design
- Lightweight desktop experience
- Local-first workflow

## Code Templates

CodeFlux includes ready-to-use templates to help you start projects and common programming tasks faster.

### C#

- Classes
- Interfaces
- Enums
- Console applications
- Unity scripts
- Common programming structures

### GDScript

- Nodes
- Characters
- Enemies
- Managers
- Singletons
- Common Godot scripts
