# Contributing to CodeFlux

Thank you for your interest in CodeFlux.

CodeFlux is developed by FunLogic Studios, and contributions, suggestions and feedback are welcome.

## Before Contributing

Please check existing issues before creating a new issue or pull request.

## Reporting Bugs

Use the Bug Report issue template and provide:

- A clear description of the problem
- Steps to reproduce it
- Your CodeFlux version
- Your operating system
- Any useful screenshots or logs

## Suggesting Features

Use the Feature Request template.

Explain:

- What you want to add
- Why it would be useful
- How you think it could work

## Pull Requests

Please keep pull requests:

- Focused on one change
- Clearly described
- Easy to review
- Free from unrelated changes

## Code of Conduct

Please be respectful and constructive when participating in the CodeFlux project.

Thank you for helping improve CodeFlux.
