# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in CodeFlux, please do not publicly disclose the vulnerability through a GitHub issue.

Instead, contact FunLogic Studios privately with:

- A description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any relevant technical information

Please allow reasonable time for the issue to be investigated and addressed before publicly disclosing it.

## Supported Versions

The latest released version of CodeFlux is the primary supported version.

Older versions may no longer receive security updates.
